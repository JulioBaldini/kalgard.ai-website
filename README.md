# KALGARD Systems Website

A modern, responsive website for KALGARD Systems - showcasing advanced drone navigation technology and visual navigation modules.

## 🚁 About KALGARD Systems

KALGARD Systems pioneers the next generation of drone navigation technology, developing advanced visual navigation systems that enable autonomous flight with unmatched precision and reliability.

## 🎨 Design Features

- **Modern UI/UX**: Clean, professional design with KALGARD's signature teal color scheme
- **Responsive Design**: Optimized for all devices and screen sizes
- **Interactive Elements**: Smooth animations and hover effects
- **Accessibility**: Built with web accessibility standards in mind

## 🛠 Tech Stack

- **Framework**: Next.js 14 with React 18
- **Styling**: Tailwind CSS with custom KALGARD color palette
- **Animations**: Framer Motion for smooth interactions
- **Icons**: Lucide React for consistent iconography
- **TypeScript**: Full type safety throughout the application

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/website-KALGARD.git
cd website-KALGARD
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
