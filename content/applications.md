# KALGARD Systems - Target Applications

## Primary Applications

### Defense and Security UAVs

MerlinSight supports UAV operations that need resilient localization when GNSS performance becomes unreliable or hostile.

### Critical Infrastructure Monitoring

The system is relevant for inspection and monitoring missions where operators need continuity of localization around strategic infrastructure.

### GNSS-Degraded Operations

KALGARD targets environments where satellite positioning can be degraded, unavailable, jammed, or spoofed.

## Public Advantages

1. Resilient onboard localization when GNSS cannot be trusted
2. Map-based correction from observed environmental features
3. Flight-tested localization error below 5 m
4. UAV integration focus for operational platforms
5. INRIA incubation and active field validation
