# KALGARD Systems - Technical Overview

## Public Positioning

KALGARD develops resilient onboard navigation technology for UAVs operating where GNSS is degraded, jammed, spoofed, or unavailable.

MerlinSight is presented publicly as an onboard localization layer that combines aircraft-borne sensing with map-based correction from observed environmental features. Public materials should describe the operational benefit without exposing algorithmic details, reference-source assumptions, processing rates, protocols, or implementation architecture.

## Public Claims

- Onboard UAV localization for GNSS-degraded environments
- Map-based correction using observed environmental features and trusted reference data
- Flight-tested localization error below 5 m
- Validation includes a defense evaluation context
- INRIA-incubated company focused on resilient UAV navigation

## Restricted Details

Do not publish method-level details, environmental feature classes, estimation internals, update rates, latency figures, communication protocols, deployment architecture, internal APIs, test trajectories, or debugging screenshots.

These details should only be shared under an appropriate partner discussion, NDA, or controlled technical review.
