# KALGARD Logos

This folder contains all KALGARD Systems logo assets organized by type.

## Folder Structure

### `/full/`
Complete KALGARD logos with full branding elements:
- Logo with text and eagle symbol
- Various formats: PNG, SVG, JPG
- Different color variations (teal, white, black)
- High resolution versions for print

**Recommended files:**
- `kalgard-logo-full-teal.svg`
- `kalgard-logo-full-white.svg` (for dark backgrounds)
- `kalgard-logo-full-black.svg`
- `kalgard-logo-full-horizontal.png`

### `/small/`
Compact versions and icons:
- Favicon sizes (16x16, 32x32, 64x64)
- Social media profile images
- App icons and thumbnails
- Square format variations

**Recommended files:**
- `kalgard-icon-16x16.png`
- `kalgard-icon-32x32.png`
- `kalgard-icon-64x64.png`
- `favicon.ico`
- `apple-touch-icon.png`

### `/text/`
Text-only versions:
- "KALGARD SYSTEMS" wordmark
- Typography variations
- Different weights and styles

**Recommended files:**
- `kalgard-wordmark-teal.svg`
- `kalgard-wordmark-white.svg`
- `kalgard-wordmark-black.svg`

## Usage in Website

Import logos in your React components:
```jsx
import KalgardLogo from '/logos/full/kalgard-logo-full-teal.svg'
```

Or reference directly:
```jsx
<img src="/logos/full/kalgard-logo-full-teal.svg" alt="KALGARD Systems" />
```
